HOW IT GROWS ／ 製作方式

這個網站怎麼長出來

每一篇練習都由 AI 讀完 AGENTS.md 後，用同一套範本、產生器和檢查腳本完成。

四個零件

  • 規則：AGENTS.md 寫明目的、語氣、頁面結構、命名、分類和完成條件。
  • 範本：templates/note.html 固定每篇的骨架：標頭、時間／準備／地點、四段內容、上下篇導覽。
  • 產生器：python3 tools/new_note.py <slug> <分類> 自動決定編號、底色、上下篇連結，並把卡片插進首頁。
  • 檢查器：python3 tools/check.py 把規則變成 20 多項自動檢查；每次推上 GitHub 也會由 GitHub Actions 再跑一次。

新增一篇的流程

  1. 決定主題與分類。分類不在表上時，先登錄新分類。
  2. 執行產生器，得到一個填好編號、底色和連結的空白頁。
  3. 依 AGENTS.md 的寫作規則填完所有欄位與首頁卡片。
  4. 執行檢查器，修到全部通過，再在下方紀錄表補一列。

目前的分類

分類CSS 類別觀察重點
光線.light影子、反光、明暗變化
聲音.sound遠近、方向、重複的聲音
觸感.touch溫度、紋理、回彈
顏色.color色調、深淺、被忽略的顏色
節奏.rhythm重複、間隔、時間線

新增紀錄

第一版只有 01、02 兩篇。03 到 05 是之後只給 AI 一句指令、照 AGENTS.md 加上的。

練習給 AI 的指令規則幫了什麼
01 追一小段影子第一版手工完成，作為其他頁的參考範例。定下四段結構與語氣。
02 畫一張聲音地圖第一版手工完成。確認範本能套到不同感官。
03 摸一張材質地圖「依照 AGENTS.md 新增一篇觸感練習：比較三種可以安全觸碰的表面。」產生器給了編號 03 與 .touch；安全規則讓步驟避開尖銳、高溫和別人的物品。
04 數一面牆的顏色「依照 AGENTS.md 新增一篇顏色練習，主題是一面看似單色的牆。」「紀錄示例要寫具體細節」讓示例列出五種具體色調。
05 聽一個路口的節奏「依照 AGENTS.md 新增一個『節奏』分類和一篇路口觀察練習。」走過「新增分類」流程；檢查器確認分類表、CSS 和頁面三處一致。
